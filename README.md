# 有句话想对你说

一个纯静态、五幕式的表白页。打开后先看到粒子爱心，点一下进入爱心、烟花、情话，最后收束成一颗由 32 行文字组成的心，中间那句话会轻轻轮换。

页面没有数据库，也不需要构建工具，直接部署静态文件即可。

## 本地运行与调试

### 第 1 步：启动本地服务器

在 `LOVE` 目录里打开终端（Windows 用 PowerShell），运行：

```powershell
cd "F:\Python\数据分析\我与她\LOVE"
python serve.py
```

看到 `LOVE 本地预览: http://127.0.0.1:8000/` 就表示启动成功。这个窗口要**保持开着**，它就是你的本地网站；调试完按 `Ctrl+C` 关闭即可，平时不需要让它一直运行。

`serve.py` 会自动给所有文件加上“禁止缓存”的响应头，改完 `config.js`、CSS 或 HTML 后**普通刷新**就能看到最新效果，不需要反复强制刷新。

> 也可以用 `python -m http.server 8000 --bind 127.0.0.1`，但浏览器可能缓存旧的 JS/CSS，改完文件后需要按 `Ctrl+F5` 强制刷新。`serve.py` 就是为了省掉这一步。
> 不要直接双击 `index.html` 打开。页面使用 ES Module，`file://` 方式会被浏览器的模块安全策略拦住，必须通过本地服务器访问。
>
> 日志里偶尔出现的 `GET /health 404` 是外部探测请求，与本页面无关，可以忽略。

### 第 2 步：在电脑浏览器看 PC 版

用 Chrome 或 Edge 打开：

```text
http://127.0.0.1:8000/
```

浏览器窗口宽度大于 900 像素时，显示的就是 PC 版布局。

### 第 3 步：在电脑浏览器看手机版（模拟，不需要真机）

用浏览器自带的“设备模拟”就能看手机效果：

1. 打开 `http://127.0.0.1:8000/`，按 `F12` 打开开发者工具；
2. 按 `Ctrl+Shift+M`（或点开发者工具左上角的手机/平板图标）进入设备模式；
3. 在顶部下拉框里选一个手机型号，例如 `iPhone 12 Pro`；
4. **把方向切成横屏**（点工具条上的旋转图标，或把尺寸手动改成 `844 × 390`）。页面会切成手机横屏布局：16:9 舞台、更大的按钮、更紧凑的字号和间距；
5. 想切回 PC 版，把模拟宽度拖到 900 像素以上即可。

两个注意点：

- 手机**竖屏**（宽度 ≤900 像素的竖向窗口）会显示“请横屏使用”的提示，这是设计如此；调试手机版请用横屏尺寸；
- 设备模式下鼠标点按会模拟轻触、按住拖动可以模拟 3D 爱心的旋转，和真机手感基本一致。

### 第 4 步：修改内容并查看效果

所有文字、称呼、音乐、口令都在 `js/config.js`（各项含义见下一节）。改完**保存文件 → 浏览器按 F5 刷新**即可；如果感觉没更新，按 `Ctrl+F5` 强制刷新绕过缓存。

项目没有构建步骤，不需要 npm、不需要重新打包，改完文件刷新就生效。

### 第 5 步（可选）：用真机直接预览

想让手机连到电脑上真实预览时：

1. 把启动命令改成监听所有网卡：`python serve.py --host 0.0.0.0`；
2. 在电脑上运行 `ipconfig`，找到“无线局域网适配器 WLAN”下的 **IPv4 地址**，例如 `192.168.1.100`；
3. 让手机和电脑连同一个 Wi-Fi，手机浏览器打开 `http://192.168.1.100:8000/`；
4. 第一次运行时 Windows 防火墙会弹窗，选择“允许访问”（专用网络）即可。

## 替换成你的内容

所有内容都在 `js/config.js`：

- `herName` / `myName`：对方和你的称呼，用于“致 …”抬头、落款，以及中央大字的回退值。
- `heartCenterText`：第二幕爱心中央的大字（默认“剩下的路，我陪你走”），留空时显示 `herName`。
- `heartNote`：中央大字下方的一句小字，留空时不显示（默认留空）。
- `theme`：`rose`、`red`、`gold` 三套主题。
- `defaultMode`：默认 `2d`；页面加载后也可以点右上角切到 3D。
- `music`：背景音乐路径，默认是 `assets/audio/bgm.mp3`。换成自己的音乐时，请确认你有使用权。
- `password`：四位数字口令。留空表示关闭；它只是页面上的轻量门禁，不是真正的安全措施。
- `paragraphs`：16 段情话，每段固定 2 行（行内不加标点），左侧 8 段、右侧 8 段。改文案时保持每段只在一侧即可；情话幕会打乱顺序随机循环播放，点“继续”才进入文字心。
- `center`：文字心中央的短句列表（每条 4–10 字）、关键词和轮换节奏；按 `lines` 的顺序逐条遍历，播完从头再来。

`js/config.js` 里的文案会自动同步到烟花后的文字幕和最后的文字心，不需要改两处。

## 资源

- `assets/audio/bgm.mp3`：默认是一段生成的占位音乐，发布前建议换成你选好的歌。
- `assets/img/share-cover.jpg`：分享封面，可用 `python tools/make_assets.py` 重新生成。
- `vendor/three.module.js`：本地 Three.js，只在切到 3D 时按需加载。

## 交互

| 幕 | 操作 |
| --- | --- |
| 开场 | 点击 / 轻触 / 回车或空格进入 |
| 爱心 | 点击“继续”，或等待按钮出现后进入烟花；右上角可切换 2D/3D |
| 烟花 | 点击空白处放一朵烟花；点击“继续”进入情话 |
| 情话 | 情话在全屏随机位置循环出现；看够了点底部“继续”进入文字心 |
| 文字心 | 中央句约每 5 秒换一句；全部归位后出现“再看一遍” |

3D 爱心支持拖动旋转；手机横屏时会使用 16:9 舞台，竖屏会提示旋转手机。

## 部署到 GitHub Pages

仓库里已经带好 `.github/workflows/pages.yml`。把 `LOVE` 目录推到 GitHub 仓库的 `main` 分支后：

1. 打开仓库的 **Settings → Pages**。
2. 在 **Build and deployment** 里把 Source 设为 **GitHub Actions**。
3. 等 Actions 跑完，页面地址是 `https://<你的用户名>.github.io/<仓库名>/`。

部署后可以在 `index.html` 里把 `og:url` 和 `og:image` 换成完整 HTTPS 地址，微信等应用分享时更容易显示封面。

## 说明

- 这是纯静态页面，口令只存在前端代码里，无法阻止懂技术的人查看源码；不要用它保护敏感信息。
- 页面默认不写入真实姓名、手机号或住址，发布前请自己检查一遍文案。
- 2D 爱心使用 Canvas 2D，3D 爱心使用 Three.js，烟花使用 Canvas 2D；没有后端和追踪脚本。
